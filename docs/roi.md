# ROI 분석 — 6주차 Agentic RAG

**측정 기준:** `results/agentic.json` (40문항)  
**비용 산출:** `make roi` 실행 결과

## 1. 측정값 — 문항 하나가 얼마인가

| 항목 | 값 | 출처 |
|---|---|---|
| 문항당 입력 토큰 | 11,061 | `results/agentic.json` usage |
| 문항당 출력 토큰 | 517 | `results/agentic.json` usage |
| 문항당 비용 | $0.00560 (약 7.8원) | `make roi` |
| 재검색한 문항 비율 | 22% | `retry_count > 0` |
| 문항당 지연 | Agentic 10.0초 / Hybrid 1.3초 | 평가 결과 |

입력 토큰은 GPT-5.4 Nano 평균 6,194개와 GPT-5.4 Mini 평균 4,867개로 구성된다. 출력 토큰은 각각 305개, 212개다.

비용 산정에는 2026년 10월 8일 기준 모델 단가를 사용하였다. 검색 과정에서 발생하는 임베딩 및 BM25 등 로컬 처리 비용은 LLM API 비용과 별도로 구분한다.

## 3. 비용 및 편익 분석

| 항목 | 월간 | 3년 |
|---|---:|---:|
| LLM API 비용 | 86,163원 | 3,101,868원 |
| CPU 서버 비용 | 300,000원 | 10,800,000원 |
| 총비용 (외부 API 제외) | 386,163원 | 13,901,868원 |
| 상담 시간 절감 가치 | 13,750,000원 | 495,000,000원 |
| 순효과 | 13,363,837원 | 481,098,132원 |

GPU 기반 자체 운영 방식은 3년 TCO 약 53,800,000원으로 가정하였다. API 및 CPU 서버 기반 방식과 비교하면 약 39,898,132원 저렴한 것으로 계산된다.

GPU 구매비 25,000,000원을 운영비 절감액으로 회수한다고 가정하면, 단순 회수기간은 약 1.9개월이다. 다만 이 기간은 상담 시간 절감 효과가 실제로 발생한다는 가정에 크게 의존한다.

## 4. 한계 및 결론

40문항 평가 결과를 전체 운영 환경으로 일반화하기에는 표본 규모가 작다. 또한 이번 계산 E2E 평가에서는 Fake LLM 사용으로 15문항 중 2문항(13.3%)만 정답 판정을 받았다. 두 정답은 계산이 필요 없는 문항이므로 실제 계산 수행 능력을 입증하지 못한다.

따라서 ROI는 확정적인 수익이 아니라 가정에 기반한 시나리오 분석으로 해석해야 한다. 실제 도입 전에는 실모델 기반 계산 정확도, 상담 시간 절감 효과, 인프라 운영비 및 품질 유지 비용을 추가로 검증해야 한다.
